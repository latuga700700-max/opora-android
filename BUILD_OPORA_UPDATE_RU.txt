ОБНОВЛЕНИЕ ОПОРА 0.2

Встроена тестовая линия: «Мои состояния → Тревога → Страх».
MP4-видео встроено непосредственно в HTML как data URI, поэтому проигрывается офлайн внутри WebView. Дополнительный исходный файл fear_video.mp4 сохранён в app/src/main/assets/.

Сборка через GitHub Actions:
1. Загрузить содержимое этого проекта в существующий репозиторий, заменив старые файлы.
2. Сохранить ветку main.
3. Открыть Actions → Build Opora APK → Run workflow (либо push в main).
4. После успешной сборки скачать Artifact Opora-debug-apk и извлечь app-debug.apk.

Существующий Android WebView и его настройки сохранены. Новые внешние разрешения для видео не требуются.
